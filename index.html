MongoDB Live Aggregations

Demonstrates both interview scenarios with single-pipeline constraints and schema index optimization.

Pipeline: $unwind → $group → $sort → $project Index Supported: { interests: 1 } Endpoint: /api/aggregations/group-by-interests

Deconstructs the user interests array with $unwind, groups users sharing the same interest together into an accumulator array with $group, and sorts by popularity in a single database aggregation.

Executing single collection.aggregate() call...

View MongoDB Aggregation Pipeline Source Code 
User.aggregate([
  // 1. Deconstruct array
  { $unwind: '$interests' },
  // 2. Group by interest
  {
    $group: {
      _id: '$interests',
      userCount: { $sum: 1 },
      users: { $push: { _id: '$_id', name: '$name', email: '$email', role: '$role' } }
    }
  },
  // 3. Sort by popularity, then alphabetically
  { $sort: { userCount: -1, _id: 1 } },
  // 4. Project clean structure
  { $project: { _id: 0, interest: '$_id', userCount: 1, users: 1 } }
]);
Pipeline: $match → $lookup → $project Index Supported: { author: 1, createdAt: -1 } Endpoint: /api/aggregations/user-posts/:userId

Executes a cross-collection join retrieving a user document along with all public posts they authored using a single $lookup stage.

Select a user above to run the $lookup aggregation pipeline.

View MongoDB $lookup Pipeline Source Code 
User.aggregate([
  { $match: { _id: targetUserId } },
  {
    $lookup: {
      from: 'posts',
      localField: '_id',
      foreignField: 'author',
      as: 'posts'
    }
  },
  {
    $project: {
      _id: 1, name: 1, email: 1, role: 1, interests: 1,
      totalPosts: { $size: '$posts' },
      posts: {
        $map: {
          input: '$posts',
          as: 'p',
          in: { _id: '$$p._id', title: '$$p.title', content: '$$p.content', createdAt: '$$p.createdAt' }
        }
      }
    }
  }
]);
